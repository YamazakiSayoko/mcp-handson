# MCP ハンズオン：社内ITヘルプデスクAIエージェント

PythonのMCP SDKとClaude APIで、**社内ITヘルプデスク向けのMCPサーバー（FAQ検索）** を作るハンズオンのコードです。
このリポジトリには、ハンズオンで使うコードだけを置いています。操作の詳しい手順は、当日のスライドで説明します。

- AIエージェントが、外部のシステムやツールとどうつながるのかを理解する
- MCPサーバーを自分で作り、AIが自分の作った機能を使うところまで体験する

## フォルダの役割

| フォルダ | 役割 |
|---|---|
| `starter_kit/` | ハンズオンの最初に使うコード一式です。`server.py` は含まれていません（ハンズオンで自分で作ります） |
| `complete_code/` | 完成版のコード（`server.py`）と、途中から追いつくためのチェックポイント（`checkpoints/`）です。詰まったときや、答え合わせに使います |

## スターターキットの入手

Gitのコマンドは使いません。ブラウザでZIPをダウンロードするだけです。
ハンズオン当日は、リモートデスクトップで接続した **Azure VMの中のブラウザ** でダウンロードしてください（手元のPCではありません）。

1. このページの緑色の **[Code]** ボタン → **[Download ZIP]** をクリックします（GitHubへのサインインは不要です）
2. ダウンロードしたZIPを右クリック →「すべて展開」します（`mcp-handson-main` フォルダができます）
3. 展開したフォルダの中の **`starter_kit` の中身** を、作業用フォルダ（デスクトップの `mcp-helpdesk-agent`）にコピーします
   - `starter_kit` フォルダごとではなく、**中身だけ**をコピーしてください

以降の手順（仮想環境の準備、ライブラリのインストール、`server.py` の作成など）は、当日のスライドに沿って進めます。

## APIキーの取り扱い

- APIキーは、このリポジトリには含まれていません。当日、講師から共有します。
- キーは、作業用フォルダの `.env` ファイルにだけ書いてください。`.env.example` には書かないでください。
- `.env` やキーを、GitHubなどのWebサービスやチャットに上げないでください。
- 画面共有やスクリーンショットに、`.env` の中身が写らないようにしてください。
