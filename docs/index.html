MCPハンズオン｜コピペ用コード集

このページは、Claude API × MCPサーバー構築ハンズオンのコピペ用コード集です。PowerPoint教材の手順に沿って、必要なコマンドやコードをコピーして使用してください。

使い方

  1. このページは、Azure VMの中のブラウザで開いてください。手元のPCでコピーしても、VMには貼り付けられないことがあります。
  2. コードの右上の［コピー］を押すと、そのコードだけがコピーされます。貼り付けは Ctrl + V です。
  3. 左上のラベルで、貼り付ける場所がわかります。
    • PowerShellターミナルに貼り付けて、Enter で実行します。1つずつ実行して、結果を確かめてから次へ進みます。
    • PythonVS Code の server.py に貼り付けます。
    • 入力例画面の入力欄に貼り付けます。
  4. Python は「行のいちばん左」から貼り付けます。
    Python のコードは、行の先頭のスペース（字下げ）もいっしょにコピーされます。VS Code で行の最後で Enter を押すと、自動で字下げが入ります。そのまま貼り付けると字下げが二重になり、エラーになります。Backspace で字下げを消して、カーソルを行のいちばん左にしてから貼り付けてください。
    貼り付けたら、左端の位置が上の行とそろっているか確かめましょう。
  5. APIキーは、このページには載っていません。講師から共有されたキーは、.env にだけ書いてください。

5. 付録：チケット登録と承認フロー

研修の時間外・持ち帰りの発展課題です。server.py に、問い合わせをチケットとして登録する register_ticket ツールを追加します。

STEP1-1register_ticketツールを追加する（import文を追加する）

場所VS Code の server.py

貼り付ける位置server.py のいちばん上に追加します。1行目のいちばん左にカーソルを置いて貼り付けると、その上に入ります。

STEP1-2register_ticketツールを追加する（保存先を定義する）

場所VS Code の server.py

貼り付ける位置mcp = MCPServer("it-helpdesk-server") の次の行に追加します。

server.py と同じフォルダに tickets.json というファイルを保存する設定です。tickets.json は、実際にチケットを登録したときに作られます。

STEP1-3register_ticketツールを追加する（register_ticket関数を追加する）

場所VS Code の server.py

貼り付ける位置search_faq 関数の下、if __name__ == "__main__": の上に追加します。if __name__ … の行のいちばん左にカーソルを置いて貼り付けると、その上に入ります。

Python
@mcp.tool()
def register_ticket(category: str, description: str) -> str:
    """問い合わせ内容をヘルプデスクのチケットとして登録する。"""
    tickets = []
    if TICKETS_FILE.exists():
        tickets = json.loads(TICKETS_FILE.read_text(encoding="utf-8"))
    new_ticket = {
        "id": len(tickets) + 1,
        "category": category,
        "description": description,
        "created_at": datetime.now(timezone.utc).isoformat(),
    }
    tickets.append(new_ticket)
    TICKETS_FILE.write_text(
        json.dumps(tickets, ensure_ascii=False, indent=2),
        encoding="utf-8"
    )
    return f"チケットを登録しました（チケット番号: {new_ticket['id']}）"
